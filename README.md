# 🧠 EL CEREBRO — Portfolio de Carlos Reyes

**Mi carta de presentación:** todo lo que he construido en un solo lugar. Proyectos IA, SaaS, productos digitales, conceptos web para clientes y mi historia.

🌐 **Live:** https://portfolio-brain-gli9iw1nn-carlosreyesafks-projects.vercel.app

## Secciones

- **Hero** — quién soy, stats animados
- **Proyectos IA** — 6 apps con inteligencia artificial (en construcción)
- **Productos & Servicios** — CobraYa, Vigia Web, servicios Chachi
- **Tienda** — 10 productos digitales en Gumroad
- **Conceptos para clientes** — 13 demos web para negocios reales
- **Mi historia** — timeline de mi journey
- **Stack** — tecnologías que domino
- **Contacto** — Upwork, LinkedIn, email

## Contenido data-driven

Todo el contenido vive en **`src/data/brain.ts`** — actualiza ese archivo y todo el sitio se actualiza. Tipado con TypeScript.

## Stack

`Next.js 14` `TypeScript` `Tailwind CSS` `Vercel`

## Desarrollo

```bash
npm install
npm run dev
```

## Deploy

Build estático + deploy a Vercel:

```bash
npm run build
python3 ~/workspace/outreach-2026-10-09/deploy.py portfolio-brain ./out
```
